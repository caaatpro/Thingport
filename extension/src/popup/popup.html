Thingport Grab

MakerWorld Printables Thingiverse

Lets your Thingport instance import from MakerWorld as you (needed for some models). Turn it off to keep the cookie in this browser.

Recent imports

Connect to your Thingport instance to import models with one click.

In Thingport, open Profile → API tokens, create a token and paste it here. Thingport Grab never asks for your password, and you can revoke the token there at any time.

If you're logged into MakerWorld in this browser, Thingport Grab reads your MakerWorld session cookie locally to import from it -- it's sent only to the instance URL above, never anywhere else.
